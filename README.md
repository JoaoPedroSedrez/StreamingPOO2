# 🎬 StreamingPOO2

Projeto desenvolvido para a matéria de Programação Orientada a Objetos II para simular uma plataforma de streaming de vídeos.  
O sistema permite gerenciar **usuários, perfis, categorias, vídeos, visualizações e avaliações**.

## 🚀 Funcionalidades
- Cadastro de usuários e perfis
- Organização de vídeos por categorias
- Registro de visualizações e progresso de cada vídeo
- Avaliação de vídeos (nota e comentário)

## 📂 Estrutura do Projeto
- **Usuario**
- **Perfil**
- **Categoria**
- **Video**
- **Visualizacao**
- **Avaliacao**
